## Prototype Discriminative Channel-Periodicity Aware Framework for MI-EEG Generalization

This repository contains the code for the research on EEG decoding.

## Datasets

- [BCIC-IV-2a](https://bnci-horizon-2020.eu/database/data-sets)
- [BCIC-IV-2b](https://bnci-horizon-2020.eu/database/data-sets)
- [BCIC-III-4a](https://www.bbci.de/competition/iii/)
- [WBCIC-SHU](https://plus.figshare.com/articles/dataset/Brain_Computer_Interface_Motor_Imagery-EEG_Dataset/22671172/3)
